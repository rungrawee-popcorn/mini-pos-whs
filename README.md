# Mini POS & Warehouse System (WHS)

## 📌 Overview

ระบบ POS และ Warehouse Management System สำหรับจัดการสินค้า การขาย และสต็อก

## 🚀 Features

- Authentication (Admin / Cashier)
- Product Management (CRUD)
- POS System (Cart / Checkout)
- Stock Management
- Sales History
- Dashboard Summary
- REST API
- Unit Test + SIT + UAT

## 🧱 Tech Stack

- ASP.NET Core 8 MVC
- C#
- Entity Framework Core
- SQL Server
- Bootstrap 5
- xUnit + Moq

## 🧪 Testing

- Unit Test
- Integration Test
- SIT Test
- UAT Checklist

## ⚙️ How to Run

```bash
dotnet restore
dotnet build
dotnet run
```
